# Capacitive_Touch_Sensor_Dev_Board
The purpose of this project is to design a capacitive touch interface that can be utilized through a USB connection.

The PCB design for a development board consists of an STM32 Microcontroller, a 6-channel capacitive touch sensor, and a USB-to-UART bridge.
